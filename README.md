# SpinGames 🎮

Site de roues et défis aléatoires pour différents jeux vidéo.

## Jeux

Les Sims 4 (SimSpin), Minecraft, Fortnite, Roblox, Stardew Valley, Animal Crossing, GTA RP et Valorant.

## Mise en ligne sur GitHub Pages

La page d'accueil est `index.html` à la racine, les fichiers de style et les scripts sont dans `assets/`, les pages de jeux dans `jeux/`. Dans **Settings > Pages**, sélectionner **Deploy from a branch**, branche `main`, dossier `/(root)`.

Les paramètres et catégories personnalisés sont sauvegardés localement dans le navigateur. Le code et les fichiers du site ont été créés pour SpinGames.
