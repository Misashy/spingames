DEVWEBGAMES — SITE WEB MULTI-PAGES (VERSION 2)
================================================

1. POUR ESSAYER LE SITE
Ouvrez index.html dans votre navigateur (Firefox, Chrome, Edge…).
Cliquez sur l'une des 8 cartes pour ouvrir la page de ce jeu.

2. LA ROUE LES SIMS 4
Chemin : jeux/les-sims-4/index.html
Cette page reprend votre fichier « index(1).html » et ses fonctions SimSpin.
Les 13 catégories et leurs choix proviennent du JSON fourni.
Une barre « Retour à DevWebGames » a été ajoutée.
Toutes les anciennes fonctions SimSpin sont conservées : un lancer tire dans
chaque catégorie cochée, gestion des nombres de tirages, sans doublons,
historique, import/export, musique et personnalisation.

IMPORTANT : si vous aviez déjà une sauvegarde SimSpin dans le stockage local
du MÊME domaine et du MÊME navigateur, elle reste prioritaire sur les valeurs
initiales. Pour importer explicitement les 13 catégories, utiliser le bouton
« Importer » et le fichier jeux/les-sims-4/mes-categories-sims.json.

3. LES AUTRES PAGES
Chacun des 7 autres jeux a sa propre page dans jeux/<nom-du-jeu>/index.html.
Les roues de ces jeux sont personnalisables et gardent leurs données localement
dans le navigateur. Il est possible de choisir plusieurs catégories, d'adapter
les listes, d'importer/exporter des catégories et de voir l'historique.

4. PUBLICATION SUR IONOS
- Vérifiez que votre contrat IONOS inclut un hébergement Web (et pas uniquement
  un nom de domaine).
- Décompressez cette archive sur votre ordinateur.
- Sur IONOS, ouvrez le gestionnaire de fichiers de l'espace Web ou utilisez SFTP.
- Transférez le CONTENU du dossier « DevWebGames-site-v2 » vers le dossier web
  associé à votre domaine, en conservant tous les sous-dossiers et chemins.
- L'accueil doit être index.html à la racine du dossier associé au domaine.
- Attendez la mise en place du HTTPS/SSL et testez chaque page sur le domaine.

Le domaine exact et le forfait IONOS sont encore à confirmer : cette archive
n'a pas été automatiquement publiée.

5. INFORMATIONS IMPORTANTES
- Les sauvegardes sont locales au navigateur. Elles ne sont pas synchronisées
  entre utilisateurs ni appareils ; pensez à exporter les fichiers JSON.
- Les liens du catalogue pointent vers jeux/<slug>/index.html pour que
  les pages fonctionnent aussi en ouvrant le site localement sans serveur.
- Les noms des jeux restent la propriété de leurs éditeurs respectifs.
- Votre fichier SimSpin contient une bande-son intégrée en audio et des éléments
  visuels. Vérifiez que vous avez les droits pour une diffusion publique avant
  de publier le site. Vous pouvez désactiver ou remplacer la musique si nécessaire.
- Les polices Google Fonts nécessitent une connexion ; le navigateur utilise
  des polices de secours si elles sont indisponibles.

6. PERSONNALISATION
- Page d'accueil : index.html / assets/site.css / assets/home.js.
- Jeux : jeux/<slug>/index.html et fichiers communs assets/game.css,
  assets/game.js. Chaque jeu contient ses propres données initiales dans
  l'élément JSON « game-data » de sa page.
- Les Sims 4 : jeux/les-sims-4/index.html.
